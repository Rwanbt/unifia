## What to do

Produce a single HTML file that looks like an internal dashboard: a
title, a row of KPI cards, a chart, and a table. Data is mocked.

## Constraints

- Inline SVG for the chart — no external libraries
- The KPI cards must use a grid layout
- The table must be sortable in place
- No third-party fonts
