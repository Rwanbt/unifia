## What to do

Produce a single HTML file with at least one interactive control. The
prototype must open in a browser without a build step.

## Constraints

- Inline CSS only — no external stylesheets or assets
- No third-party fonts; rely on the system stack
- All interactivity is plain JavaScript (no bundler)
- The page should be obvious to navigate for a non-engineer
