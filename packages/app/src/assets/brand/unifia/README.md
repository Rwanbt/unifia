# Variantes Unifia dans l'application partagée

- `unifia-app-icon-dark.svg` : icône sombre par défaut.
- `unifia-app-icon-light.svg` : support clair.
- `unifia-symbol-color-flat.svg` : petite taille et UI.
- `unifia-symbol-color-shadow.svg` : présentation.
- `unifia-symbol-black.svg` : monochrome.
- `unifia-lockup-dark.svg` : lockup carré avec nom.

La police monospace du thème est **Roboto Mono**.
