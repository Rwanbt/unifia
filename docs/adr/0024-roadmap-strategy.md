# ADR-0024: Roadmap Strategy

**Statut :** `PROPOSED`
**Date :** 2026-07-31
**Décideurs :** Erwan, Hermes Agent (MiniMax M3)
**Source :** Plan V3 §15 (Roadmap)

## Contexte

Comment publier et maintenir la roadmap Unifia ?

## Décision

**Roadmap publique** :
- **GitHub Projects** : board kanban
- **Quarterly planning** : tous les 3 mois
- **Phase planning** : 4-6 semaines par phase
- **Public Trello-like** : unifia.dev/roadmap

## Conséquences

### Positives
- Transparence
- Community feedback

### Négatives
- Engagement public = pression
