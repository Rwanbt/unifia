# ADR-0022: Org Model Strategy

**Statut :** `PROPOSED`
**Date :** 2026-07-31
**Décideurs :** Erwan, Hermes Agent (MiniMax M3)
**Source :** Plan V3 §15 (Organisation)

## Contexte

Unifia est un fork open-source. Il faut décider du modèle de gouvernance pour le projet.

## Décision

Adopter un modèle **BDFL (Benevolent Dictator For Life)** :
- **Erwan** : BDFL, décisions finales
- **Contributors** : PRs review par Erwan
- **Advisory board** : 3-5 personnes consultées pour les décisions majeures

Pas de fondation officielle (trop tôt).

## Conséquences

### Positives
- Décisions rapides
- Pas de bureaucratie

### Négatives
- Single point of failure
- Pas de succession plan

## Plan

- Phase 18 : si projet > 100 contributors, évaluer fondation
