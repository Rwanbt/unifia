```bash
ls skills/*/SKILL.md

# Lire un skill
cat skills/testing/SKILL.md
```

## Conventions

Chaque skill contient :
- **Frontmatter YAML** : `name`, `description` (avec triggers)
- **Quand m'utiliser** : liste des cas d'usage
- **Procédure** : étapes détaillées
- **Checklist** : validation points
- **Liens** : références internes
